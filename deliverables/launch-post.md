# Launch post (LinkedIn, from Sky Zhang)

Every growth team I know loses Monday mornings doing the same thing: scrolling TikTok, Reels, Reddit and HN to work out what's resonating, then guessing at a video format.

So we built Loopcast and gave that whole job to agents, on live TinyFish primitives. We pointed it at our own brand, tinyfish.ai, and the niche "AI browser agents".

One run:
→ Search found this week's threads plus 20 TikToks and Reels about the niche
→ Fetch read 8 of those threads and our own site, so every claim in the script has a source
→ Agent opened YouTube, clicked Filters → This week → Most viewed, and brought back the top Shorts. Fetch can't do this one because the data only appears after clicking.
→ Browser captured our product pages, phone-framed, as the video's footage
→ It wrote the script and rendered a 9:16 video with voiceover and captions
→ Three synthetic audience personas reviewed it frame by frame. Draft 1 scored 5.3/10 and failed, so it rewrote and re-rendered itself: v1 5.3/10 → v2 5.7/10 → v3 5.7/10. Still below the bar, so it stopped and handed the draft to a human instead of shipping it.
→ Then it stopped and waited for a human to approve. Nothing posts on its own.

Total TinyFish spend: $0.27. Wall-clock: 16.9 minutes.

The part I like most: each primitive does the one job it's actually built for. Search discovers, Fetch reads, Agent clicks, Browser takes pixels. If the Agent gets blocked, the run falls back to Search and keeps going.
