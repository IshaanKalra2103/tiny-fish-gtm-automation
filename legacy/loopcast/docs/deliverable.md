## Context

- TinyFish ships developer content steadily, but none of it has drawn the **"wait, you can DO that?"** reaction that turns a developer who is browsing into an advocate.
- Existing content shows **single calls to Search or Fetch**. It doesn't show a workflow a marketer or seller would recognize as their own job.
- **Sky Zhang (Head of Growth)** wants **one running proof point on live primitives**, not another sandboxed example, before the next round of hackathons and accelerator demos.
- TinyFish already has enterprise trust: **Google, DoorDash, ClassPass** run production workloads on it.
- The developer channel, which should make acquisition cheaper, hasn't caught fire yet.
- There is **no baseline** yet for signups, activation, or content reach, so nobody can say what "catching fire" looks like.
- Sky needs something to point the next hackathon audience and accelerator cohort at. It has to be **usable, not just impressive once**.

## My role

- **Founding DevRel & Product Marketing Manager**, reporting to Sky Zhang, inside the Product org.
- First hire in this area. There's no existing DevRel or PMM function to hand work off to.
- Work with **Homer Wang** and **Juno Chen** (Product) when a workflow choice depends on how a primitive actually behaves.
- **I decide:** which workflow to build, how to position it, and what the launch post says.
- Sky is waiting on this as the first thing worth pointing developers at.

## Hard requirements

- Use **at least 3 TinyFish primitives** from: **Search, Fetch, Agent, Browser, Vault**.
  - Each one has to do a job **only that primitive is suited for**. A primitive that's there just to hit the count doesn't qualify.
- The workflow must be one a **marketer or seller would actually run against a real target**, not a rigged example.
- It must run **end-to-end against one real target** that I choose. The demo video uses the same target.

## Deliverables (inside `tinyfish-growth-app.zip`)

| File | Format | What it is | Audience |
|---|---|---|---|
| `app.zip` | Runnable app, run instructions at the root | The working agent-led growth workflow, running end-to-end against one real target | A developer or Sky trying it firsthand before a launch or demo slot |
