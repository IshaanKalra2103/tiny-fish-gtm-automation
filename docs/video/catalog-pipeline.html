How a tool gets into our catalog

Six steps. Only tools a person approves ever reach an owner.
1

Discover

Web search for every business type and job, plus AI-tool directories

2

Read

Home, pricing, privacy, about and integrations pages

3

Extract

An AI turns the pages into a checked tool record

4

Vet

Six trust signals, each with an evidence link

5

Simulated owner test

A practice run as a busy owner, always labelled simulated

6

Human review

A person reads the record and the evidence, then approves or rejects

The pipeline runs every week, so the catalog keeps growing.
